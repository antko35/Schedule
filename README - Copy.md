СТП

1. Для текста использовать Стиль "обычный"
2. Для заголовков разделов "Заголовок 1". До и после заголовка должна быть пробельная строка.
3. Для заголовков подразделов "Заголовок 2".  До и после заголовка должна быть пробельная строка.
4. Для заголовков 3 порядка "Заголовок 3". До и после заголовка пробельной строки быть не должно.
Для сложных перечислений Использовать стиль "сложное перечисдение"
Для простых перечислений Использовать стиль "простое перечисление"
